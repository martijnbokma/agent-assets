# Agent assets

Skills by Martijn Bokma, installable through [Chain Hub](https://github.com/martijnbokma/chain-hub) (Catalog) or any tool that reads `SKILL.md` folders.

| Skill | What it does |
|---|---|
| `skills/finding-refactor-candidates` | Exhaustive tech-debt scan with coverage manifest, priority matrix and wave plan. |
| `skills/bundle-strategy-audit` | Audits code splitting, lazy loading, vendor chunks and externals. |
| `skills/module-graph-audit` | Audits barrels, tree-shaking readiness and module boundaries. |
| `skills/design-advisor` | Industry-specific UI/UX recommendations from bundled design data. |

Install with Chain Hub: open **Catalog** in the dashboard.
